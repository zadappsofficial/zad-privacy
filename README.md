# ZAD Privacy Policies — GitHub Pages

موقع سياسات الخصوصية الـ12 لبراند ZAD. كل الروابط نسبية — يعمل تحت أي اسم مستخدم أو اسم مستودع.

## النشر (دقيقة واحدة)
```bash
cd privacy-pages
git init -b main
git add .
git commit -m "ZAD privacy policies site"
git remote add origin https://github.com/<USERNAME>/zad-privacy.git
git push -u origin main
```
ثم في GitHub: Settings → Pages → Deploy from a branch → main / (root) → Save.
الرابط الثابت لكل تطبيق: `https://<USERNAME>.github.io/zad-privacy/<slug>.html`
